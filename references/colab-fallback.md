# Colab 備援

當電腦關機，可使用 repo 內的 `colab/phone_quick_cut.ipynb`，從自己的 Google 雲端硬碟讀素材並回存成果。Notebook 內嵌所需程式與資產，不依賴作者電腦的磁碟或其他技能。

## 使用

1. 將 notebook 複製到自己的 Google 雲端硬碟，以 Colab 開啟。素材放在自己有權使用的資料夾，例如 `手機快剪/收件匣/旅遊`。
2. 表單填寫相對 MyDrive 的素材夾路徑，以及主題、風格、比例、聲音與配樂選項。階段先選「出台詞稿（先審）」。
3. 執行儲存格，完成 Google Drive 授權。等到開始處理後再離開頁面；掛載與授權等待期間仍須保持瀏覽器可操作。
4. 在素材夾檢查 `_台詞稿.txt`、`_分鏡預覽.jpg`。可修改 `_script.json` 的旁白；修改後選「重送目前稿（不重寫）」產生新版預覽，這個模式會保留你的修改。選「出台詞稿（先審）」則會重新寫稿。
5. 確認目前腳本後，把階段改成「台詞已確認，合成」再執行。QA 通過後成片才會複製到該資料夾的 `成品/`；失敗時看 `_狀態.txt` 與 `_colab_log.txt`。

這不是常駐背景服務。運算時間、可用模型與配額依 Google Colab 當時環境而定；不要保證鎖屏後持續運作或固定幾分鐘完成。

## 資料、配樂與關機

- Google Drive 掛載會授權 notebook 存取雲端硬碟；只使用自己同意處理的生活影片，病人、病歷與研究受試者資料不放入此流程。
- Colab 的文字寫稿模式看不到接觸表，不能依它臆測畫面；審稿時應核對旁白。無可用模型時會使用模板並標示來源。
- Edge-TTS 會傳送旁白文字。預設配樂可使用本機合成和弦；MusicGen 僅在明確選用並具備選配依賴時載入。
- 成功、失敗與掛載例外都進入清理處理，嘗試卸載 Drive 並呼叫 `runtime.unassign()`。程序被強制終止、服務中斷或 Python 無法執行 finally 時，無法保證清理完成。
- 結束後在 Colab「管理工作階段」檢查；若仍有執行階段，手動中斷連線並刪除。不要只看成片存在就推論機器已關閉。

## 與桌面版差異

| 項目 | 桌面版 | Colab |
|---|---|---|
| 看圖寫稿 | 主 Agent 或支援的 CLI 可看接觸表 | 文字模型／模板不看畫面 |
| 現場對話辨識 | 可用本機 Whisper | 預設略過以節省時間 |
| 審稿 | 主 Agent 或收件匣確認／修改檔 | Notebook 階段與雲端腳本 |
| 資料落點 | 自訂本機／同步資料夾 | 自己的 Google Drive |
| QA | FAIL 不交付 | FAIL 不交付 |

## 修改與一致性

修改腳本、格式、需求檔或讀音資產後，在 repo 根目錄執行：

```bash
python -X utf8 scripts/make_colab_nb.py
python -X utf8 scripts/make_colab_nb.py --check
```

把重新產生的 notebook 一起提交。CI 檢查內嵌檔案是否同步；這項檢查驗證的是版本一致性，不能取代真實 Colab 的授權、依賴安裝、配額與關機驗收。
